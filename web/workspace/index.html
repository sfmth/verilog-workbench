A SMALL LOOP, REAL TOOLS.
  1. Connect a folder
    Start the command below with a trusted project. The companion uses your project’s configured source and test paths.
  2. Explore the design
    Run “Discover project”. Choose a top from the toolbar, then open its files from Designs or Tests.
  3. Save and simulate
    Edit a file, then Run tests. Runs first save all open edits. An external disk change stops the save with a visible conflict.
  4. Inspect the result
    Read Output and Diagnostics. In Artifacts, open a VCD waveform or download a schematic. Cancel long jobs with Stop.
  5. Keep experimenting
    Try the bundled examples folder as your companion project. Start with sv_beginner_counter or vhdl_beginner_counter. Native HDL tools must be installed.
